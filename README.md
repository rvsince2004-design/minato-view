## 🌟 Overview

This project renders a cinematic, scroll-scrubbed interactive experience dedicated to **Minato Namikaze (The Yellow Flash)**. Built purely with Vanilla JavaScript and HTML5 Canvas (no heavy external library dependencies), it delivers smooth 60 FPS transitions across multi-stage visual sequences.

### Visual Sequence Pipeline

1. **Closed Eyes (Scroll Scrub):** Opens on a high-contrast close-up portrait responding to page scroll delta.
2. **Particle Dispersion:** Deconstructs the character into hundreds of golden energy particles as you scroll deeper.
3. **Full-Bleed Speed Dash:** Accelerates into a yellow streak across the screen, mimicking the iconic Flying Raijin (飛雷神の術).
4. **Interactive Rasengan:** Renders a dynamic, spinning energy orb that smoothly tracks mouse and touch pointers across the screen in real-time.
5. **Ghost Cursor & Ambient Thunder:** Concludes with an atmospheric final frame illuminated by dynamic lightning flashes and ghost trail cues.
